# 咒腕哈桑重置基线

本文件是咒腕哈桑（Cursed Arm Hassan）的内容总结和重置草案。当前只整理设计，不代表 Java、JSON、玩家卡或 NPC 已经按新规则实现，也不把未由用户确认的技能数值当成最终规格。

## 1. 身份与状态

| 项目 | 内容 | 状态 |
| --- | --- | --- |
| 真名／建议 id | 咒腕哈桑／Hassan of the Cursed Arm／`cursed_arm_hassan` | 用户已确认角色；id 沿用现有实现 |
| 职阶 | Assassin | 项目现有身份；作品版本待确认 |
| 属性 | 秩序·恶 | 用户已确认；数据层分别记录为 `lawful` 与 `evil` |
| 副属性 | 人 | 用户已确认；对应 `human` |
| 时代 | 古代／`ancient` | 项目既有时代表；方案默认沿用 |
| 人物特性 | 男性、人、秩序、恶、从者、人型、人科从者、七骑士的从者 | 用户已确认 |
| 战斗定位 | 近中距离伏击、隐匿接近、短刀投掷、单体概念即死 | 方案默认 |

“Assassin”是职阶，不额外作为人物特性重复计算；“人”副属性、“人”、“人型”、“人科从者”和“活人”分别记录。用户给出的特性没有“活人”，因此重置时不应自动补回 `living_human`。

## 3. 原作能力与本地转换

原作资料入口：[FGO Wiki：咒腕哈桑](https://fgo.wiki/w/咒腕哈桑)。本稿按用户提供的 FGO Wiki 特性与参数口径整理，技能名称和等级作为原作资料候选；实施前仍应核对该页面及对应设定文本。常用 Assassin 灵基能力整理为：

| 能力 | 本地形态 | 状态 |
| --- | --- | --- |
| 气息遮断 A+ | 职阶被动；未攻击、未受实际伤害时维持隐匿，攻击或施放攻击性技能后解除 | 原作候选；本地形态方案默认 |
| 投掷（短刀）B | 共用的短刀投掷技能，玩家与 NPC 使用同一发数、伤害、MP 和冷却 | 原作候选；本地数值方案默认 |
| 自我改造 C | 主动强化；不附送无来源的回血、无敌或永久属性 | 原作候选；本地形态和数值待确认 |
| 风除けの加护 A | 针对可察觉的投射物攻击进行回避；需与公共闪避规则合并，不能另叠一份隐藏概率 | 原作候选；本地触发与效果待确认 |
| 妄想心音（扎巴尼央）C | 对人单体宝具，以概念性即死为核心；失败分支如何造成伤害与诅咒属于本地改编 | 原作候选；本地规则方案默认 |

FGO 追加技能不纳入本设计。当前咒腕定义中的 `stealth_d` 与 `spiritualization_b_plus` 不应继续作为最终技能列表：前者把气息遮断降为 D，后者是项目中小次郎透化技能的复用路径，不是咒腕本轮已确认的能力。

## 4. 被动能力

### 气息遮断 A+（职阶技能，方案默认）

- 使用现有 `ServantConcealment` 机制，隐匿本身不提供额外伤害、暴击、无敌或固定闪避。
- 维持条件：未进行攻击、未施放攻击性技能，且未承受实际伤害。闪避或无敌完全挡下的攻击不算实际伤害，是否立即破隐沿公共隐匿规则处理。
- A+ 档属于公共隐匿系统的完美隐匿档，不生成等级泄漏粒子；不把“完美隐匿”解释成无敌或额外战斗倍率。
- 解除隐匿后，玩家和 NPC 共享重新进入隐匿的条件；NPC 不能免费获得玩家没有的额外隐身层。

### 风除けの加护 A（方案默认，待确认）

将可察觉的投射物纳入公共防御／闪避判定，不直接增加所有伤害来源下的随机闪避率。待确认的边界包括哪些伤害类型算投射物、视线/感知要求、每次攻击是否只判定一次，以及近战和范围伤害是否完全不受影响。NPC 旧代码的随机回避不能未经确认直接视为最终规则。

### 自我改造 C（方案默认，待确认）

建议改为玩家卡和 NPC 共用的主动技能，避免旧实现中 NPC 自动叠三层、玩家只获得药水效果的分叉：

- 消耗 20 MP，冷却 300 ticks，持续 200 ticks；成功受理时扣费并启动冷却。
- 持续期间自身基础攻击进入独立 `×1.15` 修正区；不增加最大生命，不立即治疗，不提供无敌或减伤。
- 施放期间可以移动和普攻；再次施放不能叠层，只刷新或在冷却结束后重新开始。
- NPC 在生命比例不高于 60% 且目标进入近中距离时使用；玩家由技能槽输入使用。

这是对“身体改造”设定的实时战斗转换，不是 FGO 回合制数值搬运。若用户希望保留当前的三阶段身体变化，应另定阶段阈值、属性增量和重登/解除变身清理规则后再实施。

## 5. 专属武器与视觉状态

- 常驻武器为短刀，建议继续放在副手；主手保持空手，避免主副手入口重复扣费。生成短刀属于装备工具，不是额外宝具或追加技能。
- 普通短刀攻击走公共物理伤害、防御、闪避和友敌过滤，不根据“人型”或“从者”自动追加特攻。
- “咒腕”是妄想心音的表现来源；未释放宝具时不生成独立的免费远程伤害实体。
- 斗篷破损、绷带解除只作为表现状态。建议玩家与 NPC 统一在生命不高于 50% 时破损，妄想心音前摇期间暂时解除绷带，结束后恢复；这些状态不改变属性。
- 现有“不伤害猪族”和被动回避其他咒腕目标属于 NPC 人格规则 `spare_pigs` 与战术过滤，不是人物特性或伤害倍率。若保留，应明确只影响目标选择，不扩展为全局和平机制。

## 6. 主动技能与动作

以下为可实现的首轮方案默认值；伤害均为基础值，经过公共战斗修正和防御。20 ticks = 1 秒。

| 输入／槽位 | 名称 | MP | 冷却 | 基础效果与用途 |
| --- | --- | ---: | ---: | --- |
| 2 | 生成短刀 | 0 | 40 ticks | 生成或补充一把专属短刀；没有合法装备位置时不扣资源、不进冷却 |
| 3 | 投掷（短刀）B | 8 | 40 ticks | 3 把短刀，间隔 2 ticks，单把 14 点物理伤害；最大 18 格、逐段检查视线和碰撞 |
| 4 | 影遁·背袭 | 10 | 120 ticks | 8 格内可见目标；寻找目标身后安全落点并瞬移，随后一次 1.65 倍基础短刀伤害；穿墙、无落点时失败 |
| 5 | 影袭·突进 | 7 | 85 ticks | 6.5 格内直线突进，一次 1.05 倍基础短刀伤害并施加轻微击退；真实碰撞，不穿墙 |
| 6 | 自我改造 C | 20 | 300 ticks | 见被动栏，持续 200 ticks，攻击 ×1.15；不叠加 |
| 被动 | 风除けの加护 A | 0 | 无 | 对符合条件且已察觉的投射物走公共闪避判定；具体规则待确认 |
| 9 | 妄想心音（扎巴尼央） | 80 | 1400 ticks | 见宝具栏；对人单体，前摇 20 ticks |

槽位不要求填满。若保留现有玩家卡布局，0 号可以作为气息遮断的手动入口，但该入口必须和 NPC 使用同一隐匿状态、资源和解除规则，不能成为玩家专属的额外隐身层。

### 共同施放规则

- 施放前验证 MP、冷却、目标、视线、碰撞和维度；没有合法条件时不扣 MP、不进入冷却。
- 成功受理后立即扣 MP 并启动冷却；前摇或延迟命中被打断不退款。死亡、解除变身、离线、跨维度或区块卸载时取消延迟命中。
- 同一次技能的每个段号、每个目标最多结算一次；不通过清空 `invulnerableTime` 绕过公共受伤无敌帧，除非本轮另外确认多段规则。
- 投掷短刀的 3 个实体属于同一施法者，保留所有者、友敌过滤、命中归属和寿命；短刀撞方块、离开维度或命中目标后按公共投射物规则结束。

## 7. 宝具：妄想心音（扎巴尼央）

| 项目 | 方案默认 |
| --- | --- |
| 真名 | 妄想心音／Zabaniya: Delusional Heartbeat |
| 等级／分类 | C／对人 |
| 目标 | 1 个同维度、可见、距离不超过 7 格的合法目标 |
| 消耗／冷却 | 80 MP／1400 ticks（70 秒） |
| 前摇／命中 | 20 ticks；锁定施放时目标，命中时再次检查存活、距离、视线和友敌 |
| 反制 | 可闪避，可被打断；不可用普通格挡抵消概念即死判定；无目标或无合法位置时不受理 |
| 对人限制 | 仅对具有人型/人科从者或人类语义的目标进行即死判定；亡灵、节肢动物、动物、无心或超大型 Boss 排除 |

命中流程固定为：

1. 进行公共无敌、闪避、概念免疫和因果切断检查；被完全规避的命中不扣目标生命，也不施加诅咒。
2. 合法对人目标以方案默认 `p = 0.60` 进行一次即死判定。成功时由公共概念伤害入口处理；赫拉克勒斯的十二试炼、其他即死抗性和因果切断各按自己的公共规则去重。
3. 即死失败时造成 55 点基础宝具伤害，并施加 160 ticks 的咒腕诅咒：攻击力最终修正 -15%、护甲最终修正 -15%，附加虚弱 I。重新命中只刷新持续时间和同名减益，不叠加第二份 -15%。

即死概率、非致死伤害以及“是否对魔力先于非致死伤害结算”仍属于高影响待确认项；上表是为了让玩家卡和 NPC 可以先共享同一条执行路径。

## 8. 伤害与叠加示例

普通短刀、投掷和影袭没有隐藏的人型/从者特攻。自我改造启用时，示例为：

`最终伤害 = 基础物理伤害 × 1.15（自我改造启用时） → 公共防御与最终修正`

因此投掷 3 把短刀全部命中同一目标的基础合计为 `3 × 14 = 42`；自我改造期间为 `42 × 1.15 = 48.3`，再进入护甲和其他公共防御。妄想心音的 55 点非致死伤害只属于该宝具，不套用短刀伤害或其他角色的特攻。

## 9. 玩家卡与 NPC AI

玩家卡和咒腕 NPC 共享参数、隐匿、风除け判定、短刀投掷、影遁、突进、自我改造、MP、冷却、妄想心音目标过滤和诅咒效果。AI 只改变选择时机：

- 先利用隐匿接近，3～10 格优先投掷或背袭，贴身使用普通短刀和突进。
- 目标被墙体、地形或其他实体阻挡时优先影遁；没有合法落点不消耗资源。
- 妄想心音优先选择孤立、可见且具有人型语义的目标；非人型目标不得为了触发伤害而强行施放。
- 生命较低时使用自我改造；任何公共保命或致死处理由公共入口负责，AI 不得提前免费回血。
- 当前 `preferred_range=7`、`style=ambusher`、`retreat_health_ratio=0.22` 可作为 AI 初始配置，但不改变核心数值。

## 11. 待确认项

1. 是否采用 `Presence Concealment A+`、`Throwing (Dagger) B`、`Self-Modification C`、`Wind Protection A` 这组能力；其中风除け是否只影响可察觉的投射物。
2. 自我改造采用本文的限时 `×1.15`，还是保留三阶段身体属性变化；若保留三阶段，需要确定阈值、增量、是否治疗以及解除变身/重登处理。
3. 妄想心音的即死概率是否为 60%；非致死 55 点是否走普通防御/魔抗，还是采用独立的概念伤害入口。
4. 是否保留“不伤害猪族”和“默认不主动攻击其他哈桑”的 NPC 人格规则；这两项不应写成全局特攻。
5. 是否保留现有 0 号隐匿输入；若保留，需确认开启 MP、持续和玩家/NPC 共用方式。

## 12. 验收范围

- 身份、参数、`human` 副属性和八项人物特性读取正确，且没有 `living_human` 的隐式补全。
- 气息遮断 A+ 的隐匿、攻击破隐、实际伤害破隐和 NPC/玩家一致性正确。
- 短刀投掷 3 段只按施放者归属一次结算，投射物不会穿墙、误伤盟友或重复命中。
- 自我改造不免费回血、不叠层，解除变身、死亡、跨维度和重登不会残留状态。
- 妄想心音的前摇、目标锁定、闪避/打断、概念即死、十二试炼扣命、非致死伤害、诅咒刷新和异常退出均可复算。
- 玩家卡和 NPC 在相同目标、距离、MP、冷却和状态下得到相同核心结果；差异只出现在 AI 选招和动作表达。

纯设计阶段不宣称以上验收已经通过；实现后再补单元测试、GameTest、客户端和专用服务器结果。
