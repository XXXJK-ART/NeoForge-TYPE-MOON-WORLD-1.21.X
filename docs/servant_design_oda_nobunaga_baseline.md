# 织田信长设计案例：通用规范的来源

整理日期：2026-10-18。此案例保存本次讨论中的用户选择与重置方案，供后续设计参照；不作为源码已完成或游戏测试通过的证明。后续用户修改只更新相应角色规则，不反向改写其他英灵。

## 1. 身份与参数（用户已确认）

- 角色：织田信长／Oda Nobunaga，Archer，人物参数采用帝都圣杯战争版本。
- 参数：筋力B、耐久B、敏捷B、魔力A、幸运A-、宝具E～EX。A-按A÷2，系数25。
- 特性：女性、人、秩序、中庸、王、从者、人型、七骑士的从者、信长、人科从者。
- 时代：大航海。其余已约定时代见 [通用规则](servant_design_rules.md)。
- 资料参考：<https://fgo.wiki/w/织田信长>；本地设计优先，不采用FGO追加技能。

## 2. 被动

| 能力 | 设计 |
| --- | --- |
| 对魔力B | 保留职阶被动，本轮不重做公共魔抗 |
| 独立行动B | 只影响御主死亡后的现界时间，删除附带的随机增伤与暴击加成 |
| 火焰免疫 | 用户明确保留常驻火焰／岩浆等原有免疫；不会随显现结束而消失 |
| 战略B | 对军／对城宝具双向被动修正；整理默认B档增伤16%、减伤16%，E～A阶梯4/8/12/16/20% |
| 魔王A | 保有被动占位，无数值效果；与主动显现分开 |
| 天下布武·革新A | 提供神性与时代特攻；用户选择保留原有神性破防，并把它归入本被动 |

天下布武覆盖信长造成的近战、枪弹、主动、宝具、技能爆炸和持续技能伤害。神性E／D／C／B／A的额外加成为+1／+2／+3／+4／+5，单独总倍率分别×2／×3／×4／×5／×6。

时代额外加成：神话+3、古代+2、大航海+1、近现代0；现代和未来不加特攻，分别在最终伤害上×0.5、×0.25。用户已更正：**近现代没有特攻也不减半，现代才减半。**

用户选择三千世界骑乘特攻也进入同一个加算区：

`特攻倍率 = 1 + 神性加成 + 时代加成 + 三千世界骑乘加成`

其中最后一项仅三千世界满足骑乘条件时为1，其他情况为0。神性E＋神话是×5；再加入宝具骑乘则为×6，不是另乘2。

神性破防保留已有的清除抗性提升、伤害吸收、抗火和5秒破防标记等行为；不得在该被动之外再叠一套旧神性倍率。

## 3. 火绳枪、武器与飞行

用户已确认：

- 作战火绳枪为30生命、可破坏的特殊实体。
- 同维度6格内自己的所有浮空作战枪都可代伤；依次扣枪，全部耗尽后溢出到信长本体。
- 自动布阵、追击阵、火网、宝具等作战枪均可参与；飞行枪坐骑保留120生命，不参与该代伤。
- 压切长谷部左右手持有均可；删除普通左键射击，保留右键射击。
- 飞行优化为创造飞行的速度、加速和操作手感，其余已有资源与飞行机制保留。

整理方案默认：代伤按由近到远处理，先通过免疫／闪避，再扣枪，溢出进入本体防御；右键沿用3MP／16ticks／18点基础伤害；飞行保留G键模式、高度约束、0.28MP/tick和退出条件，疾跑速度按原版×2。以上默认可由后续设计调整，不是其他角色的通用常量。

## 4. 主动技能（用户给定主体数值）

下列伤害为基础值，随后结算天下布武等修正。

| 输入 | 名称 | MP／冷却ticks | 内容 |
| --- | --- | --- | --- |
| 蹲下左键 | 压切长谷部·一闪 | 8／40 | 突刺4.5格，首个敌人受15物理伤害；神性目标击退5格；骑乘目标追加5把枪齐射 |
| 槽位0 | 火绳枪·自动布阵 | 20／200 | 最多5把环绕枪，存在30秒，每1.5秒自动射击最近敌人，每发10物理伤害 |
| 槽位1 | 三段击·轮转齐射 | 30／200 | 三波，每波10枪各1发，间隔0.5秒，约60°扇形，每发10；当批射完消失 |
| 槽位2 | 火绳枪·追击阵 | 40／160 | 视线内30格锁定，10枪围绕目标依次各1发，自动修正弹道；每连续3发全中追加20爆炸伤害 |
| 槽位3 | 狙击·火绳枪 | 50／300 | 按住蓄力2秒，伤害10→50，弹速3→4格/tick；满蓄击退 |
| 槽位4 | 交叉火网·封锁 | 35／240 | 前方14格或锁定目标当前位置布14枪，固定持续8秒；每枪每秒1发、每发10，网内移速−30% |
| 槽位5 | 焦土战术·烈焰焚城 | 40／400 | 半径7格，三波、间隔1秒，每波8火焰伤害；结束后地面燃烧5秒，踏入者每秒5火焰伤害 |
| 槽位6 | 压切长谷部·烈火突进 | 25／150 | 冲刺3.5格，路径所有敌人各受22物理伤害；结束后5枪各射3发，每发10，扇形散布 |
| 槽位7 | 第六天魔王·显现 | 45／500 | 持续15秒，攻击+30%、移速+15%；站在火焰中每秒恢复5生命，常驻免疫仍保留 |

追击阵的用户确认口径为：总共10发，连续3发命中同一目标触发一次爆炸，落空中断连中，最多3次。

一闪的骑乘条件追加齐射是特殊触发效果，**没有骑乘伤害倍率**；骑乘伤害倍率只属于三千世界。

整理方案中的补全默认：

- 自动布阵24格索敌，只补足5把，不刷新旧枪寿命；满枪不扣费。
- 一闪追加5枪各1发，每发10；烈火突进的三连射间隔4ticks。
- 火网半径5格；焦土中心在施放时固定，使用可清理的地火表现和技能伤害，不永久烧毁地形、不重复叠加原版火伤。
- 狙击40ticks线性蓄满，满蓄击退力度1.0；冲刺、突刺、击退不穿越方块。
- 追击计数在一次技能内按发射序处理；触发后重置，落空或枪被提前摧毁中断；附加爆炸只伤主目标，不破坏地形。
- 显现的攻击+30%整理为自身造成伤害×1.3，精确移速+15%，避免用不等价药水档位代替。

## 5. 宝具与AI

| 宝具 | 消耗／冷却 | 内容 |
| --- | --- | --- |
| 三千世界 | 95MP／3600ticks | 对军宝具；99枪，每枪3发，每发基础10；短按跟随自己，长按留在原地；骑乘额外+1进入特攻加算区，不分E～A等级 |
| 第六天魔王波旬 | 130MP／3600ticks | 原领域主体不变；初次基础伤害统一52，后续每秒12，取消旧普通／神性两组基础伤害差异；所有神性增伤交由天下布武 |

用户明确：NPC与玩家统一宝具消耗、冷却及效果，实体同步本次设计，基础动作类小技能可以保留。

整理方案默认：三千世界长按阈值12ticks，两个宝具沿用玩家现有共享冷却；波旬按对神宝具记录，不吃战略对军／对城加成。波旬保留35+95分段支付、吟唱、15秒持续、约25格作用范围、原有异常状态、领域往返、临时地形恢复及维度不可用的本地回退。NPC保留选招和吟唱动作，不保留与重置冲突的旧主动战略回蓝、免费补枪或独立的额外倍率。

## 6. 可复算的验收例子

不考虑其他状态、阵营与目标防御时：

| 场景 | 结果 |
| --- | --- |
| 基础10，对神性E、神话目标 | 10×(1+1+3)=50 |
| 上述目标有骑乘，受到三千世界 | 10×(1+1+3+1)=60；加入战略B后69.6 |
| 基础10，对无神性的近现代目标 | 10，不减半 |
| 基础10，对无神性的现代／未来目标 | 最终5／2.5 |
| 三千世界全部枪完整射击 | 99×3=297发，基础合计2970；这是理论全中，不是保证命中 |
| 追击阵10发全部命中 | 10×10+3×20=160基础伤害，再分别结算伤害类型与修正 |
| 三把满血枪代伤100 | 枪承担90，剩余10进入本体防御，不是无条件扣10生命 |
| 常驻免疫挡掉火焰 | 枪不掉血，本体不受伤；显现期间按火焰接触另行判定回血 |

此案例中的特攻公式、数值与枪机制仅属于信长。后续新英灵应借用“设定有来源、数值可复算、操作明确、卡与实体一致”的方法，而非复制这套技能。
