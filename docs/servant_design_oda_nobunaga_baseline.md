# 织田信长设计案例：通用规范的来源

整理日期：2026-10-18。此案例保存本次讨论中的用户选择与重置方案，供后续设计参照；不作为源码已完成或游戏测试通过的证明。后续用户修改只更新相应角色规则，不反向改写其他英灵。

## 1. 身份与参数（用户已确认）

- 角色：织田信长／Oda Nobunaga，Archer，人物参数采用帝都圣杯战争版本。
- 参数：筋力B、耐久B、敏捷B、魔力A、幸运A-、宝具E～EX。A-按A÷2，系数25。
- 特性：女性、人、秩序、中庸、王、从者、人型、七骑士的从者、信长、人科从者。
- 时代：大航海。其余已约定时代见 [通用规则](servant_design_rules.md)。
- 资料参考：<https://fgo.wiki/w/织田信长>；本地设计优先，不采用FGO追加技能。

## 2. 被动

| 能力 | 设计 |
| --- | --- |
| 对魔力B | 保留职阶被动，本轮不重做公共魔抗 |
| 独立行动B | 只影响御主死亡后的现界时间，删除附带的随机增伤与暴击加成 |
| 火焰免疫 | 用户明确保留常驻火焰／岩浆等原有免疫；不会随显现结束而消失 |
| 战略B | 对军／对城宝具双向被动修正；整理默认B档增伤16%、减伤16%，E～A阶梯4/8/12/16/20% |
| 魔王A | 保有被动占位，无数值效果；与主动显现分开 |
| 天下布武·革新A | 提供神性与时代特攻；用户选择保留原有神性破防，并把它归入本被动 |

天下布武覆盖信长造成的近战、枪弹、主动、宝具、技能爆炸和持续技能伤害。神性E／D／C／B／A的额外加成为+1／+2／+3／+4／+5，单独总倍率分别×2／×3／×4／×5／×6。

时代额外加成：神话+3、古代+2、大航海+1、近现代0；现代和未来不加特攻，分别在最终伤害上×0.5、×0.25。用户已更正：**近现代没有特攻也不减半，现代才减半。**

用户选择三千世界骑乘特攻也进入同一个加算区：

`特攻倍率 = 1 + 神性加成 + 时代加成 + 三千世界骑乘加成`

其中最后一项仅三千世界满足骑乘条件时为1，其他情况为0。神性E＋神话是×5；再加入宝具骑乘则为×6，不是另乘2。

神性破防保留已有的清除抗性提升、伤害吸收、抗火和5秒破防标记等行为；不得在该被动之外再叠一套旧神性倍率。

## 3. 火绳枪、武器与飞行

用户已确认：

- 作战火绳枪为10生命、可破坏的特殊实体。
- 玩家飞行坐骑与NPC飞行支撑枪为50生命；被击毁后玩家或NPC需要等待60秒才能再次飞行。
- 同维度6格内自己的所有浮空作战枪都可代伤；依次扣枪，全部耗尽后溢出到信长本体。
- 自动布阵、追击阵、火网、宝具等作战枪均可参与；飞行坐骑和NPC飞行支撑枪不参与该代伤。
- 压切长谷部左右手持有均可；删除普通左键射击，保留右键射击。
- 飞行优化为创造飞行的速度、加速和操作手感，其余已有资源与飞行机制保留。

整理方案默认：代伤按由近到远处理，先通过免疫／闪避，再扣枪，溢出进入本体防御；右键沿用3MP／16ticks／18点基础伤害；飞行保留G键模式、高度约束、0.28MP/tick和退出条件，疾跑速度按原版×2。以上默认可由后续设计调整，不是其他角色的通用常量。

## 4. 主动技能（用户给定主体数值）

下列伤害为基础值，随后结算天下布武等修正。

| 输入 | 名称 | MP／冷却ticks | 内容 |
| --- | --- | --- | --- |
| 蹲下左键 | 压切长谷部·一闪 | 8／40 | 突刺4.5格，首个敌人受15物理伤害；神性目标击退5格；骑乘目标追加5把枪齐射 |
| 槽位0 | 火绳枪·自动布阵 | 20／200 | 最多5把环绕枪，存在30秒，每1.5秒自动射击最近敌人，每发10物理伤害 |
| 槽位1 | 三段击·轮转齐射 | 30／200 | 三波，每波10枪各1发，间隔0.5秒，约60°扇形，每发10；当批射完消失 |
| 槽位2 | 火绳枪·追击阵 | 40／160 | 视线内30格锁定，10枪围绕目标依次各1发，自动修正弹道；每连续3发全中追加20爆炸伤害 |
| 槽位3 | 狙击·火绳枪 | 50／300 | 按住蓄力2秒，伤害10→50，弹速3→4格/tick；满蓄击退 |
| 槽位4 | 交叉火网·封锁 | 35／240 | 前方14格或锁定目标当前位置布14枪，固定持续8秒；每枪每秒1发、每发10，网内移速−30% |
| 槽位5 | 焦土战术·烈焰焚城 | 40／400 | 半径7格，三波、间隔1秒，每波8火焰伤害；结束后地面燃烧5秒，踏入者每秒5火焰伤害 |
| 槽位6 | 压切长谷部·烈火突进 | 25／150 | 冲刺3.5格，路径所有敌人各受22物理伤害；结束后5枪各射3发，每发10，扇形散布 |
| 槽位7 | 第六天魔王·显现 | 45／500 | 持续15秒，攻击+30%、移速+15%；站在火焰中每秒恢复5生命，常驻免疫仍保留 |

追击阵的用户确认口径为：总共10发，连续3发命中同一目标触发一次爆炸，落空中断连中，最多3次。

一闪的骑乘条件追加齐射是特殊触发效果，**没有骑乘伤害倍率**；骑乘伤害倍率只属于三千世界。

整理方案中的补全默认：

- 自动布阵24格索敌，只补足5把，不刷新旧枪寿命；满枪不扣费。
- 一闪追加5枪各1发，每发10；烈火突进的三连射间隔4ticks。
- 火网半径5格；焦土中心在施放时固定，使用可清理的地火表现和技能伤害，不永久烧毁地形、不重复叠加原版火伤。
- 狙击40ticks线性蓄满，满蓄击退力度1.0；冲刺、突刺、击退不穿越方块。
- 追击计数在一次技能内按发射序处理；触发后重置，落空或枪被提前摧毁中断；附加爆炸只伤主目标，不破坏地形。
- 显现的攻击+30%整理为自身造成伤害×1.3，精确移速+15%，避免用不等价药水档位代替。

## 5. 宝具与AI

| 宝具 | 消耗／冷却 | 内容 |
| --- | --- | --- |
| 三千世界 | 95MP／3600ticks | 对军宝具；每波33枪、共3波、总计99枪，每枪1发、每发基础10；按对应枪位接续，前一把结束并消失后，间隔1秒（20ticks）在同位置补下一波的枪。原单枪间隔参数30ticks（1.5秒）保留，每枪仅1发时不再触发后续射击间隔；短按跟随，长按定点；骑乘额外+1进入特攻加算区。信长站枪升空并处于倒锥形枪阵中心，枪距0.8～1格 |
| 第六天魔王波旬 | 130MP／3600ticks | 原领域主体不变；初次基础伤害统一52，后续每秒12，取消旧普通／神性两组基础伤害差异；所有神性增伤交由天下布武 |

用户明确：NPC与玩家统一宝具消耗、冷却及效果，实体同步本次设计，基础动作类小技能可以保留。

**三千世界的枪阵演出补充（用户已确认，尺寸以最新调整为准）**：首波33把枪按3批、每批11把，由下向上沿连续螺旋显现；后续两波按对应枪位接续，总计99把枪。短按跟随模式维持螺旋并随信长移动，长按在释放位置展开固定阵形。枪显现后立即开始射击，不等待整波齐全。早期“散得很开”及后来的0.5格枪距均由最新的紧凑枪阵、0.8～1格间隔覆盖。

**波次接续（用户最新明确，覆盖此前立即接续规则）**：每个对应枪位独立推进：第1波该位置的枪完成1发并消失后，等待1秒（20ticks）补上第2波同位置的枪；第2波结束后再等待1秒接第3波。其他枪位未结束时，本位置仍独立按此间隔接续。33个位置各生成3把枪、每把1发，共99把、99发；任何位置同一时刻最多一把。被摧毁或30秒到期的枪视为已经结束，同样等待1秒接续，避免枪位卡住；死亡、解除变身或跨维度清理枪阵时取消全部后续接续，包括间隔中的待生成枪。

时序实现默认：第一波按3批由下往上显现，批间3ticks，约0.4秒展开；首把枪短暂引燃（计时器2至4ticks，实体实际第3至5tick）起射，每枪发射1发后立即消失。同位置的第2／3波在前枪消失20ticks后补上，下一实体tick即可起射，不再重复展开整波。每枪改为1发后，全套自然结束时间相应缩短，没有固定总时长。原30ticks射击间隔参数保留，其他时序参数不变。

**阵形（用户最新明确）**：整体下移，让信长处于枪阵中间；形状像上宽下窄的龙卷风／倒立圆锥，高度在10格以内，枪距0.8～1格。本地实现为约1.87圈的连续锥形螺旋：中心上下各3.675格，总高7.35格；底部半径1.5格、顶部4.5格（下口宽3格、上口宽9格）。33个枪位沿螺旋均匀升高，最近邻间距约0.92～0.93格。三波使用同一组坐标，接续不发生波间位置偏移。跟随阵形中心取本体高度55%，定点模式保留释放位置；上述精确几何为实现默认。

**玩家吟唱飞行（用户最新明确，覆盖原地悬停演出）**：开始三千世界吟唱时进入正常火绳枪飞行状态，站在枪上开始升空；玩家全程自由移动、升降、加速及双击方向冲刺。初次起飞时提供40ticks内约3格的柔和上升，水平输入始终生效，玩家一旦操作升降键便直接接管高度，不再返回起飞坐标。已经飞行时复用坐骑、保留速度与飞行模式，不再强制抬升。释放宝具或吟唱被打断后仍保持普通飞行，由玩家及既有落地／耗魔等规则退出，不自动降回或移除坐骑。正常飞行沿用0.28MP/tick、碰撞与高度规则；跟随枪阵围绕移动中的玩家，定点模式留在释放位置。吟唱特效按玩家实际位置补充，手动关闭飞行后也继续衔接至释放或中断。

NPC维持既有站枪升空、在阵中展示并于结束后返回的演出；本次自由操控调整专用于玩家。死亡、解除变身、跨维度或重载沿用既有清理规则。

**未完成枪的留存（用户已确认）**：每把枪从自身显现起最多存在30秒（600ticks），一发打完立即消失；没有可射击目标时保留剩余弹药并等待，目标死亡或失去视线后可重新索敌继续射击，不重新装填、不重置寿命。高层宝具枪的再索敌采用枪周围48格与枪口视线校验，以覆盖下方地面敌人；该搜索范围为适应更高枪阵的实现默认值。死亡、解除变身或跨维度仍按既有规则立即清理。

视觉补充：吟唱不允许出现特效空白；前摇采用瞄准纹章、3.2格上升焰线和铁环，吟唱中每40ticks补一轮短循环，衔接前一轮的余焰并覆盖完整吟唱，释放或打断后停止补充。灰色火药烟沿紧凑螺旋分布，每把枪每次发射都在枪口补灰烟，主齐射特效按实际波次播放；等待目标期间不持续堆叠粒子。魔王显现沿用独立红黑冠状螺旋、扩散压迫环与金橙铁环，主体使用透明烟焰材质保留暗红色；不与波旬领域混用。

整理方案默认：三千世界长按阈值12ticks，两个宝具沿用玩家现有共享冷却；波旬按对神宝具记录，不吃战略对军／对城加成。波旬保留35+95分段支付、吟唱、15秒持续、约25格作用范围、原有异常状态、领域往返、临时地形恢复及维度不可用的本地回退。NPC保留选招和吟唱动作，不保留与重置冲突的旧主动战略回蓝、免费补枪或独立的额外倍率。

## 6. 可复算的验收例子

不考虑其他状态、阵营与目标防御时：

| 场景 | 结果 |
| --- | --- |
| 基础10，对神性E、神话目标 | 10×(1+1+3)=50 |
| 上述目标有骑乘，受到三千世界 | 10×(1+1+3+1)=60；加入战略B后69.6 |
| 基础10，对无神性的近现代目标 | 10，不减半 |
| 基础10，对无神性的现代／未来目标 | 最终5／2.5 |
| 三千世界全部枪完整射击 | 33×3波×1发=99发，基础合计990；这是理论全中，不是保证命中 |
| 追击阵10发全部命中 | 10×10+3×20=160基础伤害，再分别结算伤害类型与修正 |
| 三把满血枪代伤100 | 枪承担30，剩余70进入本体防御，不是无条件扣70生命 |
| 常驻免疫挡掉火焰 | 枪不掉血，本体不受伤；显现期间按火焰接触另行判定回血 |

此案例中的特攻公式、数值与枪机制仅属于信长。后续新英灵应借用“设定有来源、数值可复算、操作明确、卡与实体一致”的方法，而非复制这套技能。

## 8. NPC 无人观看的波旬战斗（2026-10-23）

用户已确认：仅织田信长 NPC 适用；释放时没有拉入玩家，等待 3～5 秒后带全部参与者退出，并按基础面板和对神情况掷加权骰子，结果包括信长胜、对方胜、都没赢、都死。原因是无人观看的结界维度不会持续加载，无需模拟实际战斗。玩家施放不使用此规则；NPC 拉入玩家时仍使用原有真实结界。

实现默认：纯 NPC 战斗在原维度暂时隐去所有参与者，暂停实体更新、移动和受伤；服务器独立计时 60～100ticks，随后一起恢复再结算，不依赖跨维度加载。正常 130MP 消耗及 3600ticks 共享冷却保留；不再另算结界首击和持续伤害。多人目标作为对方阵营合计，不只结算主目标。卸载、死亡、外部跨维度或停服会取消尚未完成的骰子并恢复全部参与者，重载也恢复此前的隐身、无敌、AI、重力状态。

以下权重属于本轮实现默认，可继续调整，不作为新的通用战斗数值：

- 基础评分：筋力×25%＋耐久×25%＋敏捷×20%＋魔力×20%＋幸运×10%，复用公共参数换算，保留 +、A-、A++；宝具 EX 不强行换成固定系数。
- 血量修正：评分乘以 `0.25＋0.75×当前生命比例`。普通生物没有英灵面板时，以基础攻击、最大生命、基础移速折算。
- 每个对手的有效评分为 `自身评分÷天下布武倍率`；倍率复用 `OdaRules.special(神性, 时代, false)×OdaRules.eraFinal(时代)`，对神和时代只计算一次，不附带三千世界骑乘或战略倍率。所有对手的有效评分相加。
- 设信长有效份额 `p＝信长评分÷双方总评分`，接近程度 `c＝1－|2p－1|`。都没赢概率 `5%＋10%×c`，都死概率 `1%＋4%×c`；剩余概率按 p 分给信长胜，按 1－p 分给对方胜。

双方原始评分和血量相同时的示例：

| 对手 | 信长胜 | 对方胜 | 都没赢 | 都死 |
| --- | --- | --- | --- | --- |
| 无神性、无时代克制 | 40% | 40% | 15% | 5% |
| 神性 E、神话（天下布武×5） | 74.44% | 14.89% | 8.33% | 2.33% |
