# 库丘林 Lancer 重置基线

更新：2026-10-22。适用 Minecraft 1.21.1、NeoForge 21.1.242、Java 21、PlayerAnimator 2.0.4+1.21.1。

## 1. 身份与设计依据

本轮依据用户贴出的完整重置方案及后续修正实施。人物原作依据为《Fate/stay night》的 Lancer 库丘林；本轮未重新查证外部资料，卢恩含义及下表实时战斗数值均为本地改编，不冒充原作规则。排除 FGO 追加技能。

| 字段 | 内容 |
| --- | --- |
| 真名／id | 库丘林／Cu Chulainn／`cu_chulainn` |
| 职阶／副属性 | Lancer／天 |
| 秩序轴／道德轴 | 秩序／中庸 |
| 时代 | 神话，沿项目既定归属 |
| 特性 | 神性、从者、人型、Lancer、男性、天、秩序、中庸、天地从者、所爱之人、人科从者、七骑士从者 |
| 定位 | 中近程单枪与卢恩辅助，失去实体枪后需回收，低血量获得背水增伤 |

## 2. 基础参数

| 筋力 | 耐久 | 敏捷 | 魔力 | 幸运 | 宝具 |
| --- | --- | --- | --- | --- | --- |
| B | C | A | C | E | B |

参数、神性及对魔力的属性换算复用公共服务。移除错误的 `living_human`，不将人型与人科从者混为一项。

## 3. 被动与恢复

- **四枝之浅滩 A**：保有被动，本地背水规则为 `1 + 0.30 * (1 - clamp(当前生命/最大生命, 0, 1))`。普通攻击、技能、火球、投枪、召回及宝具由统一伤害事件乘算一次，治疗不参与；满血 ×1、半血 ×1.15、20%生命 ×1.24。
- **避矢之加护 B**：保留现有防御和行动限制，不增加发射者视野限制。
- **对魔力 C／神性 B**：保留已有职阶／公共技能来源及适用规则，不另添无来源倍率。
- **战斗续行 A**：采用公共 A 档，不叠加额外保命次数或重整旗鼓被动。
- **脱战恢复**：只在实际造成或承受正伤害时记录时间。1200ticks 后满生命、满 MP、清除可解除负面效果；NPC 保留目标也能恢复。空挥、施法、闪避及完全吸收不重置。技能、宝具、续行冷却均不改变。

## 4. 实体枪与输入

开始右键时固定蹲伏模式，途中蹲起不切换。可以使用实际装备魔枪的主手或副手，枪术每段重新检查持枪状态。

| 输入 | 行为 | MP／冷却 |
| --- | --- | --- |
| 非蹲右键不足20ticks | 锁定4格内准星附近可见合法目标 | 0／无 |
| 非蹲右键至少20ticks | 死棘，受理时重新检查5格距离与视线 | 20／600ticks宝具组 |
| 蹲右键不足40ticks | 普通投枪，举枪后第5tick脱手，射程48格，首次命中24物伤后插地 | 0／20ticks独立组 |
| 蹲右键至少40ticks | 死翔，吟唱后跳跃再投枪 | 300～600／1200ticks宝具组 |

锁定持续600ticks，只在再次成功锁定时刷新；死亡、过期、跨维度清除。保留锁定不放宽死棘距离。死翔优先选48格内可见锁定目标，否则按准星与既有远程索敌处理。

`CuSpearLedger` 为世界级唯一权威，记录原 ItemStack（含组件）、归属 UUID、原手、票据、实体和维度；枪实体携带外观副本，不负责生成可拾取物品。状态覆盖在手、飞行、插地、返回、待归还。在手通过清除已归还记录表示。物品实际脱手后禁止再次生成；NPC 默认装备补枪也检查记录。

回程速度2.4格/tick，约每前进6格左右交替偏移1.5格，最后3格直回。按移动线段检测，每目标最多一次24物伤，排除本人、御主、盟友及免疫玩家。窄路径破坏遵守公共配置、地形保护事件及玩家破块事件；容器、不可破坏块保留，拒绝破块不阻止回收，不掉落方块。

原主3格内交互直接归还；其他人交互触发同样的Z字返回，不扣 MP。重复交互不重复伤害或归还。原手被占则入背包，背包满保留待归还，创造模式也不能吞掉原物品。跨维度、离线、卸载／重载使旧实体失效，记录待归还，恢复有效后只归还一次。解除变身／死亡清除卡牌生成枪，普通实物按正常掉落或归还规则处理。

MP与冷却在共享执行器成功受理时计算；卢恩、重整旗鼓、召回不要求持枪。可解除负面效果沿现有特殊诅咒规则；同名效果刷新、不叠加。

| 1 | Laguz·流动 | 20／160 | 速度III及海豚恩惠11秒，水下呼吸20秒，抗火8秒 |

火球速度1格/tick、射程24格，发射时瞄准目标当前位置，不跟踪、不穿墙，每颗直接伤害一次，点燃只刷新。半弧半径1.6格。Berkana定时治疗总计64点，药水再生另计。

**结界最新用户修正**：从最初边长4.3格缩小至边长2.2格的等边立方体，刚好罩住玩家；六个浅青透明面、12条粒子描边使用同一尺寸常量。受击闪亮，耗尽／到期消失；不放置真实方块，也不增加保护别人的能力。取消过密的白色大粒子。

公共重整旗鼓 E～A 等级表见 `servant_design_rules.md` 第14节。

## 6. 宝具

**穿刺死棘之枪／Gae Bolg**：对人宝具，基础250；读取玩家卡／NPC共享身份的幸运，保留旧即死、防御及特殊防御交互与近战追击。与死翔共享持有者上的宝具冷却。

**突穿死翔之枪／Gae Bolg**：对军宝具。40ticks支付300MP，对应500基础伤害；之后每tick增加10MP，70ticks达到600MP／1000基础伤害。实际支付不足蓄力额但至少300时按实际支付计算：`500 * payment / 300`，支付封顶600。四枝在基础伤害封顶后结算，不被1000再次截断。

松开时验证资源、着地与起跳空间后进入已有吟唱；效果时再次检查，垂直冲量1.2格/tick、保留水平移动，最高点／撞顶或最多等待20ticks后投枪，落地前免本次跳跃落伤。吟唱中断沿公共规则退50%实付、冷却减半；效果阶段起跳失败也不移走物品并按该规则退款。实际投出后不退款。

保留原有10支分裂、追踪、范围与每次施放的单目标伤害预算；仅主枪可归还原物品。分裂没有可拾取物，主枪结束插地且落地不追加宝具伤害。

## 7. 伤害算例

基础伤害乘四枝一次，再进入原有护甲、魔抗、特殊防御及其他公共能力处理。Tiwaz修改普通攻击属性，不把固定技能又乘攻击属性+30%。

| 场景（其他修正均为1） | 防御前结果 |
| --- | --- |
| 满血横扫两段 | 12×2＝24 |
| 半血横扫两段 | 12×1.15×2＝27.6 |
| 20%生命连刺全中 | 10×1.24×3＝37.2 |
| 半血、70tick死翔 | 1000×1.15＝1150 |
| 450MP死翔、20%生命 | 750×1.24＝930 |
| 上例再受某目标最终20%减伤 | 930×0.8＝744；只有目标确实持有对应能力时适用 |

无额外标签特攻，多重特攻不适用。火焰理论直接合计50；两段横扫单目标24、最多三目标合计72；连刺单目标30。仅指定技能命中临时处理受伤间隔，不修改目标对其他伤害的免疫帧。

## 8. 玩家与NPC、动作及枪光

玩家卡、物品兼容入口和 NPC 选招共用 `CuChulainnAbilityService`、`CuChulainnWeaponService` 和 `CuChulainnRules`。AI优先收枪，低血主动重整／治疗，近程横扫／连刺，远程卢恩，满足 MP、冷却、距离、视线及起跳条件才用宝具；没有免费技能或额外脱战恢复。

**后续用户要求**：按迪尔姆德已接入的 PlayerAnimator 前置制作动作。玩家由其动作层播放，NPC 用同一前置库采样相同关键帧；上身、肩关节、握持与物品姿态共用数据，不再用正弦摆臂替代NPC动作。保留原版视线、行走和下半身移动。主副手与左右惯用手做镜像映射。

横扫两次转肩、连刺三次送枪并衔接收势，投枪先举手蓄势再向前投出。共享服务器起始tick对齐动作，实际枪尖由与握持渲染相同的模型矩阵采样。红色渐隐枪光和细粒子跟随枪尖，实体飞行／回程另有红色拖尾；不增加伤害。

## 9. 替换与默认值

移除低血自动重整、NPC五秒脱战回满、重复扣费及旧定时治疗路径。保留 C 档技能id、公开物品和技能兼容入口；新增 E～A 定义、四枝、火球、持久枪与必要客户端同步。

用户已确认身份、共享规则、输入与恢复边界；数值／演出按贴出方案的实施默认执行。结界正方体及缩小要求、动作前置和红色枪光为本轮后续明确修正。没有需要阻塞实施的待确认参数。
