# 库丘林 Lancer 重置基线

更新：2026-10-22。适用 Minecraft 1.21.1、NeoForge 21.1.242、Java 21、PlayerAnimator 2.0.4+1.21.1。

## 1. 身份与设计依据

本轮依据用户贴出的完整重置方案及后续修正实施。人物原作依据为《Fate/stay night》的 Lancer 库丘林；本轮未重新查证外部资料，卢恩含义及下表实时战斗数值均为本地改编，不冒充原作规则。排除 FGO 追加技能。

| 字段 | 内容 |
| --- | --- |
| 真名／id | 库丘林／Cu Chulainn／`cu_chulainn` |
| 职阶／副属性 | Lancer／天 |
| 秩序轴／道德轴 | 秩序／中庸 |
| 时代 | 神话，沿项目既定归属 |
| 特性 | 神性、从者、人型、Lancer、男性、天、秩序、中庸、天地从者、所爱之人、人科从者、七骑士从者 |
| 定位 | 中近程单枪与卢恩辅助，失去实体枪后需回收，低血量获得背水增伤 |

## 3. 被动与恢复

- **四枝之浅滩 A**：保有被动，本地背水规则为 `1 + 0.30 * (1 - clamp(当前生命/最大生命, 0, 1))`。普通攻击、技能、火球、投枪、召回及宝具由统一伤害事件乘算一次，治疗不参与；满血 ×1、半血 ×1.15、20%生命 ×1.24。
- **避矢之加护 B**：保留现有防御和行动限制，不增加发射者视野限制。
- **对魔力 C／神性 B**：保留已有职阶／公共技能来源及适用规则，不另添无来源倍率。
- **战斗续行 A**：采用公共 A 档，不叠加额外保命次数或重整旗鼓被动。
- **脱战恢复**：只在实际造成或承受正伤害时记录时间。1200ticks 后满生命、满 MP、清除可解除负面效果；NPC 保留目标也能恢复。空挥、施法、闪避及完全吸收不重置。技能、宝具、续行冷却均不改变。

## 4. 实体枪与输入

开始右键时固定蹲伏模式，途中蹲起不切换。可以使用实际装备魔枪的主手或副手，枪术每段重新检查持枪状态。

| 输入 | 行为 | MP／冷却 |
| --- | --- | --- |
| 非蹲右键不足20ticks | 锁定4格内准星附近可见合法目标 | 0／无 |
| 非蹲右键至少20ticks | 死棘，受理时重新检查5格距离与视线 | 20／600ticks宝具组 |
| 蹲右键不足40ticks | 普通投枪，举枪后第5tick脱手，射程48格，首次命中24物伤后插地 | 0／20ticks独立组 |
| 蹲右键至少40ticks | 死翔，吟唱后跳跃再投枪 | 300～600／1200ticks宝具组 |

锁定持续600ticks，只在再次成功锁定时刷新；死亡、过期、跨维度清除。右键锁定显示目标名、确认音和短暂标记，持续提示剩余秒数，失败与失效也有提示。保留锁定不放宽宝具距离：显式锁定目标超出死棘5格／死翔48格或被遮挡时释放失败。没有锁定时，两种宝具随机选择各自范围内可见合法敌人，可选背后目标；没有合格目标不扣MP、不进冷却。吟唱结束时重新验证选中目标。

`CuSpearLedger` 为世界级唯一权威，记录原 ItemStack（含组件）、归属 UUID、原手、票据、实体和维度；枪实体携带外观副本，不负责生成可拾取物品。状态覆盖在手、飞行、插地、返回、待归还。在手通过清除已归还记录表示。物品实际脱手后禁止再次生成；NPC 默认装备补枪也检查记录。

回程速度2.4格/tick，沿固定回收轴约每前进8格左右交替偏移，单侧最宽6格、横向总宽12格，近距离按初始距离的30%收窄，最后3格直回。用逐段计数决定左右换向，保证实际横跨中心线。按移动线段检测，每目标最多一次24物伤，排除本人、御主、盟友及免疫玩家。窄路径破坏遵守公共配置、地形保护事件及玩家破块事件；容器、不可破坏块保留，拒绝破块不阻止回收，不掉落方块。

原主3格内交互直接归还；其他人交互触发同样的Z字返回，不扣 MP。重复交互不重复伤害或归还。原手被占则入背包，背包满保留待归还，创造模式也不能吞掉原物品。跨维度、离线、卸载／重载使旧实体失效，记录待归还，恢复有效后只归还一次。解除变身／死亡清除卡牌生成枪，普通实物按正常掉落或归还规则处理。

插地枪使用0.8格宽、2.2格高的交互命中箱，普通与精确右键交互均可取枪；模型采用手持显示相同的0.5／0.6／0.6缩放，并把枪尖移至插地点，避免原比例的巨大地面枪。

**结界最新用户修正**：从最初边长4.3格缩小至边长2.2格的等边立方体，刚好罩住玩家；六个浅青透明面、12条粒子描边使用同一尺寸常量。受击闪亮，耗尽／到期消失；再次按6号技能立即主动解除，即使技能仍处于冷却或开启动作期间也有效，不再扣MP、不刷新冷却。不放置真实方块，也不增加保护别人的能力。取消过密的白色大粒子。

Ansuz／Laguz／Tiwaz／Algiz／Berkana及结界启动均出现对应卢恩粒子，并播放唤术与水晶共鸣音效；沿用已有符文纹理和粒子类型。

公共重整旗鼓 E～A 等级表见 `servant_design_rules.md` 第14节。

## 6. 宝具

**穿刺死棘之枪／Gae Bolg**：对人宝具，基础250；读取玩家卡／NPC共享身份的幸运，保留旧即死、防御及特殊防御交互与近战追击。与死翔共享持有者上的宝具冷却。

**突穿死翔之枪／Gae Bolg**：对军宝具。40ticks支付300MP，对应500基础伤害；之后每tick增加10MP，70ticks达到600MP／1000基础伤害。实际支付不足蓄力额但至少300时按实际支付计算：`500 * payment / 300`，支付封顶600。四枝在基础伤害封顶后结算，不被1000再次截断。

松开时验证资源、目标、地面或距地0.6格内及起跳空间后进入已有吟唱；吟唱中轻微离地、走下台阶或主动跳跃不再使效果阶段误判失败。水／熔岩、头顶空间被封闭仍会失败；起跳垂直冲量1.2格/tick、保留水平移动，最高点／撞顶或最多等待20ticks后投枪，落地前免本次跳跃落伤。吟唱中断沿公共规则退50%实付、冷却减半，不改变公共受击打断窗口；效果阶段起跳失败或目标失效也不移走物品并按该规则退款。实际投出后不退款。

保留原有10支分裂、追踪、范围与每次施放的单目标伤害预算；仅主枪可归还原物品。分裂没有可拾取物，主枪结束插地且落地不追加宝具伤害。

死翔分裂爆炸的方块清除按距各自爆心的三维距离由近到远执行，包含爆心方块，呈球形向外扩散；不再并行执行低硬度方块的横向扫描。沿用原18格半径、公共分帧预算和方块保护规则。

## 7. 伤害算例

基础伤害乘四枝一次，再进入原有护甲、魔抗、特殊防御及其他公共能力处理。Tiwaz修改普通攻击属性，不把固定技能又乘攻击属性+30%。

| 场景（其他修正均为1） | 防御前结果 |
| --- | --- |
| 满血横扫两段 | 12×2＝24 |
| 半血横扫两段 | 12×1.15×2＝27.6 |
| 20%生命连刺全中 | 10×1.24×3＝37.2 |
| 半血、70tick死翔 | 1000×1.15＝1150 |
| 450MP死翔、20%生命 | 750×1.24＝930 |
| 上例再受某目标最终20%减伤 | 930×0.8＝744；只有目标确实持有对应能力时适用 |

无额外标签特攻，多重特攻不适用。火焰理论直接合计50；两段横扫单目标24、最多三目标合计72；连刺单目标30。仅指定技能命中临时处理受伤间隔，不修改目标对其他伤害的免疫帧。

## 8. 玩家与NPC、动作及枪光

玩家卡、物品兼容入口和 NPC 选招共用 `CuChulainnAbilityService`、`CuChulainnWeaponService` 和 `CuChulainnRules`。AI优先收枪，低血主动重整／治疗，近程横扫／连刺，远程卢恩，满足 MP、冷却、距离、视线及起跳条件才用宝具；没有免费技能或额外脱战恢复。

**2026-10-23 用户修正：NPC 只使用枪术，不加入体术。** NPC 会在 3～7 格、视线可达时选用既有突进，AI 至少间隔 60ticks 再选，技能自身仍共用 0MP／18ticks 冷却／24点伤害。突进在第3tick落下唯一伤害判定，先位移再命中，与既有枪刺关键帧一致；使用正常实体移动和碰撞，不瞬移穿墙。

从迪尔姆德单红枪动作复用、适配五组 NPC 枪术：双向横扫、舞枪连击、普通舞枪、直刺和斜扫。横扫／连刺可随机采用新演出，仍分别按原第6／12tick两段、第4／8／12tick三段判定，MP和冷却不变。普通攻击在三种枪术中切换，均仅第5tick结算一次既有普攻，整次间隔至少20ticks；视觉转枪不增加命中次数、额外伤害或控制。保留原版头部追踪及下半身行走，不增加踢击、肘击等体术。

NPC 在 5～48 格可主动使用普通投枪：起手和第5tick释放时均复核敌对、存活、同维度、距离及视线，向目标实体当时的位置投掷，仍是普通24点伤害及20ticks独立投掷冷却。死翔在公共吟唱可打断窗口受到真实伤害后，NPC 可在40ticks内衔接同一普通投枪入口；继续使用原宝具50%返还、半冷却，不重置普通投枪冷却、不复制枪、不继承死翔伤害或分裂。目标消失／跨维度／死亡时清理衔接，控制及技能禁用期间不出手；环境导致起跳失败不触发此伤害打断衔接，玩家不自动补投。

投枪命中、插地，或飞行超过30ticks后，NPC 才请求既有收枪技能，避免刚出手便召回。回收仍消耗8MP、共享60ticks冷却；返程中不重复扣费。使用原持久枪账本及实体返程，原枪回到原手，不创建第二把枪。

**同日后续：两个宝具的动作、语音与特效。** 死棘在吟唱后先追近，再执行玩家／NPC共用的18ticks专用突刺：第6tick才结算原250伤害及原即死判定，随后收势；追近不再直接结算击杀。动作有明确收枪、转肩、前送、伸枪和回收过程，保持头部及下半身原版行为，不增加伤害段数。旧NPC宝具入口也转至同一武器服务，避免绕过吟唱与动作。

死翔保留吟唱期间原可打断窗口及失败资源规则。成功起跳即提交投出：举枪8ticks后开始投掷动作，再过5ticks真正发射；这段已释放演出不因目标移动／消失、视线改变或后续控制而静默丢失。目标失效时投向起跳时记录的目标位置；死亡、离开维度或失去原枪仍清理。起跳前目标无效及头顶碰撞仍按原失败规则处理，不伪造成功。

两个宝具共用原完整语音资源，但客户端按施法者UUID持有各自跟随实体的声音实例，吟唱不受普攻语音门限影响。中断只停止该施法者的吟唱，不再向所有玩家停止同名音效而误切其他库丘林；实体追踪稍晚时短暂等待后播放。旧NPC攻击语音在宝具语音窗口内静音，避免覆盖。

两个宝具的蓄力加密为枪尖24粒子／tick、周身双螺旋24粒子／tick及每3ticks的32点脚下光环，远于32格减半主体密度；仍无额外伤害。卢恩按后续反馈改为少量符文点缀：普通卢恩仅起手3枚，Ansuz仅保留5个发射位各1枚，不重复堆叠。演出主体改为对应效果的粒子：火焰与薄烟、水花与水滴、强化暴击光与电火花、防护光点、治疗绿光与自然微粒、结界电光；每3ticks的旋转环也使用对应元素粒子。玩家与NPC共用，技能数值和宝具特效不变。死棘命中另有红色贯穿轨迹及爆点，便于识别实际命中。

**收枪衔接。** 仅原枪真实返还到手后播放12ticks单枪舞枪收势，玩家与NPC共用，并接原枪回手音效；飞回途中不提前播放，待领／重登恢复不凭空重播。NPC等收势后继续选招，玩家仍可立即响应后续操作。该动画不付费、不造成伤害、不重置回收冷却。

**后续用户要求**：按迪尔姆德已接入的 PlayerAnimator 前置制作动作。玩家由其动作层播放，NPC 用同一前置库采样相同关键帧；上身、肩关节、握持与物品姿态共用数据，不再用正弦摆臂替代NPC动作。保留原版视线、行走和下半身移动。主副手与左右惯用手做镜像映射。

横扫两次转肩、连刺三次送枪并衔接收势。**最新用户修正**：投枪与蓄力动作只驱动右侧持枪臂和物品轨道，副手／左惯用手沿既有映射镜像；身体、另一只手与双腿保持原版姿态，不额外转肩扭身。停用原版长矛使用姿态，避免双套动作叠加。共享服务器起始tick对齐动作，实际枪尖由与握持渲染相同的模型矩阵采样。红色渐隐枪光和细粒子跟随枪尖，实体飞行／回程另有红色拖尾；不增加伤害。

死棘和死翔长按到阈值后进入稳定举枪，松手后的吟唱与跃起继续显示枪尖红色聚能粒子，粒子7ticks后消失；静止蓄力不画宽光带。中途换枪／停止使用清理动作。攻击、死亡、胜利及宝具语音使用用户目录中的8条MP3转单声道Vorbis资源，玩家与NPC复用触发及语音门控，宝具沿公共吟唱服务播放原完整语音，避免与攻击语音重叠。

## 9. 替换与默认值

移除低血自动重整、NPC五秒脱战回满、重复扣费及旧定时治疗路径。保留 C 档技能id、公开物品和技能兼容入口；新增 E～A 定义、四枝、火球、持久枪与必要客户端同步。

用户已确认身份、共享规则、输入与恢复边界；数值／演出按贴出方案的实施默认执行。结界正方体及缩小要求、动作前置和红色枪光为本轮后续明确修正。没有需要阻塞实施的待确认参数。
