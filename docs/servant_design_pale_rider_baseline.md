# 苍白骑士：4.0 适配重置

日期：2026-11-01。范围：现有 Rider 灵基适配 Minecraft 1.21.1／NeoForge 21.1.242 与项目公共从者系统。

## 1. 依据与本轮边界

- **用户已确认**：主要做新版适配，尽量少改机制；对魔力直接使用公共规则。
- **用户提供**：中立·中庸，副属性天，筋力 E／耐久 A／敏捷 B／魔力 A／幸运 C／宝具 EX。
- **本地既有约定**：时代 `mythology`，职阶 Rider，原 ID `pale_rider`。
- **资料状态**：本轮没有新增经核实的作品引用。用户指出其未在 FGO 实装；下列技能及数值来自仓库现有实现，不冒充官方 FGO 技能或官方特性表。
- **实施默认**：保留完整技能布局和战斗循环。本轮不执行此前整理稿中的大幅精简，不删除既有概念死亡、恩奇都四倍判定、位移或瘟疫地形机制。

## 2. 身份、参数与特性

| 字段 | 最终记录 |
| --- | --- |
| 真名／外文／ID | 苍白骑士／Pale Rider／`pale_rider` |
| 职阶 | Rider |
| 副属性 | 天：`faction=heaven` |
| 秩序轴／道德轴 | 中立 `neutral_alignment`／中庸 `balanced` |
| 时代 | 神话 `mythology`，仅元数据，不新增时代倍率 |
| 六项参数 | E／A／B／A／C／EX |
| 用户要求的特性 | `servant`、`rider`、`riding`、`heaven_or_earth_servant`、`neutral_alignment`、`balanced` |
| 延续的本地标签 | `genderless`、`conceptual_existence`、`apocalypse_horseman`、`plague`、`false_rider`、`system_servant`；不据此新增隐含强化 |

`riding` 表示拥有骑乘能力，替换旧的永久 `mounted` 标签；是否真的骑着宿主或天启马由运行状态决定。`servant` 沿用公共从者／EA 判定，不额外发明一套 EA 特攻。

基础属性直接采用 `ServantParams`：生命 500，基础攻击 5，基础移动速度属性 0.32，基础护甲 1.5，魔力池 1000，基础暴击率 6%。护甲韧性继续走公共公式；装备、状态和公共战斗流程另算。删除 NPC 的 400 生命／0.36 移速／12 护甲硬编码，生成与读档都由父类初始化，不因读档补血或补 MP。

宝具参数 EX 与具体宝具条目 A 分开记录；EX 不乘进任何固定伤害。

## 3. 五项技能与特殊机制

| 技能 | 分类 | 本轮承接的效果 |
| --- | --- | --- |
| 对魔力 C | 职阶被动，公共 `magic_resistance_c` | 仅抵抗已标记的魔术：二道咏唱及以下免疫，更高复杂度伤害减免 22%；负面效果抗性采用公共 C 档 35%，只通过公共魔术效果入口结算。普通药水、未标记伤害与普通宝具不自动视为魔术 |
| 骑乘 EX | 职阶被动，本地特殊实现 | 保留附身普通受控非玩家生物、鼠群、乌鸦及合格灵魂回响；不能附身从者、从者卡玩家、Boss 与禁用宿主。没有固定附身时限；宿主移动保留碰撞；伤害转交宿主，原有专属穿透例外继续有效 |
| 感染 A | 保有被动＋召唤／攻击传播 | 最多五层，刷新期 100ticks；每秒伤害依次 1／5／10／15／20，每 40ticks 执行传播调度，邻近传播搜索 5 格。叠层、控制及解除继续用 `InfectionRules`／`PaleRiderInfectionService`，不另外套毒或凋零 |
| 无辜的世界 EX | 保有被动 | 现有 NPC 的 15 格恐惧光环：攻击属性乘 0.85；同一来源对同一目标每 600ticks 最多检查一次，30% 概率恐惧 30ticks。离开后攻击惩罚按现有 30ticks 标记到期清理 |
| 冥界的引导 EX | 保有机制＋可切换主动 | 灵魂库最多 100；优先实体化最强的 50 个灵魂；移动领域 50 格。关闭时回收仍存活灵魂，战死灵魂消耗；不捕获从者灵魂。它是开关领域，技能数据持续时间改为 0，不再误写为 60 秒 |

感染基础传播概率依层为 20／30／40／50／60%；普通生物控制概率及原版生物修正沿用原表，玩家和从者不进入普通生物控制。控制单位总上限 100，NPC 乌鸦另有 50 只限制。治愈赋予免疫时沿用 600ticks 免疫；不是所有自然到期都附送免疫。

鼠群满编 20 只、每只对应 5 生命，满编实体 100 生命，保留受伤拆分和合并；单鼠锚点 5 生命。乌鸦 10 生命、基础攻击 2。召唤物保留原所有者、友敌过滤、受控命令和宿主交接，不新增永生能力。

## 5. 宝具：剑、饥馑、死、兽

等级 A，对军，ID `sword_famine_death_beast`。使用 25 格移动领域；领域锚点沿用本体／附身时的显现代理。资料参数 EX 不改变条目等级。

开启 300 MP，重开冷却 3600ticks，维持每秒 10 MP；不足时结束，玩家支持公共契约供魔及公共无限模式，不再直接只读本卡 MP。无需存在感染敌人才能维持。动作记录的 60ticks 前摇／200ticks 活跃／35ticks 收招是现有 AI 威胁时序记录，不是领域自动关闭计时；领域为持续开关。

| 灾厄 | 沿用实现 |
| --- | --- |
| 饥馑 | 每秒基础伤害 5；NPC 额外延续 25% 攻击惩罚，标记 30ticks |
| 剑 | NPC 每秒两把、每把随机基础伤害 30～50；玩家每 40ticks 一把、基础伤害 35；初速 1.6 格/tick，寿命最多 60ticks，普通碰撞投射物，并非必中 |
| 死 | NPC 每 200ticks 对感染者判定；一至五层成功率 1／5／10／15／20%；失败基础伤害 100，成功按既有概念死亡流程；原有阿瓦隆保护例外继续沿用 |
| 兽 | NPC 原有领域鼠群／乌鸦生成及对应天启表现；天启马与骑士表现单位沿用不可直接伤害、领域结束时清除的规则 |

本轮为饥馑、概念剑、概念死的实际伤害附加公共宝具来源包装，保留原伤害类型与所有者，使战略、宝具防御及魔术分类能读取正确来源。普通感染和鼠群咬伤不会因为由苍白骑士发出就自动成为对军宝具。

## 6. 伤害结算及兼容例外

- 对魔力只结算一次：NPC 不再在 `hurt` 中预乘 0.8。100 点已标记高等魔术 → 公共 C 档后 78 点 → 其他公共防御；二道咏唱及以下为 0。未标记的普通 magic 类型不会仅因类型名触发对魔力。
- 苍白骑士旧专属命中恩奇都采用最终伤害区独立 ×4，其他对象 ×1；本轮不扩展适用对象。例如未计防御时 5 点饥馑分别为 5／20。普通感染五层一秒基础 20，对恩奇都旧结算为 80；是否穿越对方宝具防御仍由原判定处理。
- 冥界 NPC 的每 10 个存活显现灵魂一档：移速 +5%、MP/s +1、受伤乘 `1 - 0.05 × 档数`，最多五档；不与宝具参数 EX 相乘。高等魔术与五档冥界组合，在其他防御前为 `100 × 0.78 × 0.75 = 58.5`。
- 固定技能伤害不再额外乘筋力等级；多段仍遵守现有 MC 无敌帧和各入口已有的重置规则，不声称全部理论命中必然相加。

**本轮保留的旧入口差异（实施默认，理由为限制适配范围）**：玩家没有 NPC 自动恐惧光环、冥界灵魂档位强化、概念死亡与领域兽群自动生成；突进／脉冲的感染层数、攻击盒、剑生成节奏也保留旧值。NPC 选招阶段仍为原逻辑：80% 以下考虑冥界，60% 以下考虑四灾，生命越低鼠群补充越频繁。这里只统一本轮涉及的参数、对魔力、共用 MP／冷却常量和宝具来源，不宣称所有旧技能已完全统一。

领域地形腐化仍走 `PaleRiderCorruptionService` 的旧真实方块改写，包括土壤、植物与脚下灵魂沙；**旧实现不会自动恢复这些方块**。本轮保留此既有行为，不将其写成已完成的临时地形或恢复系统。关闭／死亡／解除／跨维度／离线的原有实体回收与状态清理入口继续使用；停止地形调度不等于恢复方块。

## 7. 本轮改动与验收

实际改动：身份参数与特性、NPC 公共属性初始化、公共对魔力 C、四灾费用与冷却记录、感染／冥界持续时间元数据、宝具伤害来源、公共持续供魔、灰烬步落点碰撞。旧资源 ID 保持兼容，未删除的旧专属对魔力 JSON 只留 C 等级、不再提供角色专属数值。

验证入口：

```powershell
.\gradlew.bat test --tests 'net.xxxjk.TYPE_MOON_WORLD.servant.palerider.*' -I tools/pale-rider-validation.init.gradle
.\gradlew.bat runGameTestServer -I tools/pale-rider-validation.init.gradle '-PgameTestNamespaces=typemoonworld_palerider,typemoonworld_magecraft'
.\gradlew.bat runClient -I tools/pale-rider-reset-smoke.init.gradle
.\gradlew.bat test build
```

游戏测试覆盖：参数与特性、保存重载不回血／补 MP、玩家与 NPC 对魔力共用表、伤害进入公共事件前不额外减免、三类四灾伤害的对军分类和归属、普通感染不冒充宝具、魔力不足时领域结束。客户端辅助模组只在指定验证脚本中加载，不进入发布 JAR。

2026-11-01 实际结果：

- 苍白骑士规则单测 5／5 通过；四项新增适配 GameTest 与十一项公共魔术回归合计 15／15 通过，运行于独立专用服务器测试世界。
- 客户端与集成服务器验证通过，日志标记 `PALE_RIDER_CLIENT_SMOKE_PASS`；验证实际玩家同步的 500 生命、NPC 属性、公共 C 档、鼠群／乌鸦及双领域开启。
- 全量单测 621 项中 620 项通过。唯一失败为工作区已有幽弋改动与 `ShadowHassanResourcesTest.java:88` 的“不能有 8 号槽”断言冲突；本轮未修改该角色的实现或断言。
- 因上述既有失败，正常 `test build runClient` 在单测阶段停止；随后执行 `build runClient -x test` 完成打包及客户端验证，不将跳过测试的构建写成全量测试通过。
- 产物：`build/libs/Type_Moon_World-neoforge-4.0-mc1.21.1.jar`。这是当前完整工作区的构建，包含工作区原有的其他未提交改动。
- 验证日志：`build/pale-rider-targeted.log`、`build/pale-rider-gametest.log`、`build/pale-rider-final-validation.log`、`build/pale-rider-client-build.log`。原有资源加载日志仍报告 `magic_output` 标签引用及 `durandal_survival` 配方缺失，本轮没有更改相关资源。

未全面验证所有旧技能的平衡、地形恢复、全生命周期和所有玩家／NPC 差异；这些项目没有被本轮轻量适配替换为新设计。
